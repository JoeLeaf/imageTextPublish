# v0.2 本机验收记录

日期：2026-10-12。环境：Windows x64，Electron 44.7，Node.js 22。

## 实现

- 独立 ImageX Apply → 字节上传 → Commit，使用账号实时 STS、官网服务配置与真实用户 ID。
- 当前官网图文页使用 legacy `create/` 表单。字段由正常网页源码核对，详见 `current-creator-schema.md`；未复制参考项目代码。
- 图片预览后再次核对哈希，将同一份已核对字节传给上传器，不在上传时重新读取路径。
- 最终请求使用账号 Chromium 页面原有 fetch 与网页 SDK 签名，不模拟点击发布。
- Chromium 联网前拦截所有签名探测；实际提交只允许带当前一次性票据的签名请求通过一次，拦截网页重试与无票据请求。
- 平台回执必须同时满足成功业务码、2xx、无损且一致的作品 ID。网络中断、未知错误或矛盾 ID 都进入待核对。
- 同账号所有任务共享间隔与不确定结果阻塞；休眠中断准备，普通暂停等待当前稿件结束。
- 全文预览保留原文并显示正文/标题字数，超限要求调整；不静默截断。单文本最大 1 MiB，单图最大 50 MiB。

## 验证边界

`npm test` 11 个文件、122 项测试通过；TypeScript 与生产构建通过，生产依赖审计 0 漏洞。离线测试使用模拟服务响应，覆盖真实 SQLite、调度、图片读取限制、上传原语、桥接和提交门禁，不能代替平台接收作品的实际验证。测试后执行 `npm run setup` 恢复 Electron 原生模块版本。

真实会话已核实身份与上传授权。网页会为创作请求注入 `msToken`、`a_bogus`，探测全部在联网前取消；签名注入仅证明网页处理了请求，不证明平台最终接受作品。真实最终发布与审核结果需用户在界面启动首条任务后确认。

macOS 尚未实机验收；本机关闭、休眠或应用退出期间不会执行任务。私有接口与网页 SDK 可能变化，失败时应更新适配器。

## 真实图片上传

真实账号临时授权下，独立实现对一张程序生成的 320×240 PNG 完成 Apply、transfer 和 Commit，平台返回 320×240。当前官方上传网关返回 `*.bytedancevod.com` 节点，已加入受限域名并测试拒绝仿冒后缀。所有最终 create 路径在此脚本联网前拦截；未创建作品。STS、UID、上传 URI 均未写入日志或持久文件。

## 真实提交前完整通路

以真实账号运行本应用 AccountSessionManager、CreatorBridge、DouyinAdapter，使用合成 PNG 和固定测试文案完成实际上传，核对文案、仅自己可见、timing=-1 与上传尺寸。正常网页 SDK 为最终 legacy create 请求注入签名与真实浏览器 metadata；额外的 onBeforeSendHeaders 门禁在联网前取消该请求。只观察到一次最终发送尝试，适配器正确返回 uncertain，网页重试未再通过。未创建作品，不写入真实任务数据。

真实官网编辑页也曾上传合成图并捕获被取消的最终表单，确认 legacy create 与 timing=-1，捕获文件移除了上传 URI，未记录签名/会话值。此诊断点击仅用于核对官网请求，产品运行时发布全部走 HTTP 协议。

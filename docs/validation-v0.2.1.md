# v0.2.1 素材选择与重复发布

- 文案与图片分别支持文件夹、单个文件或多个指定文件；指定文件不回退扫描同目录的其他文件。
- 选取文本后，“本批发布条数”默认等于有效文案文件数量；一个文件为一条，内容相同的不同文件分别计数。手动修改后，选图和扫描不会覆盖条数，重新选择文本重新计算默认值。
- 允许重复使用其他任务或发布历史中的文案。创建、保存预览与发布均不按历史文案哈希查重。旧发布记录仍保留用于用户查看；不确定提交的异常处理沿用原规则。
- 配置备份保存指定文件列表，跨设备重绑定时映射文件路径并核对冻结素材。
- 单批仍为 1–1000 条；超出时显示分批提示。无效、空文案、损坏图片会列出并跳过，有效数量用于默认条数。

验证使用本地临时素材与隔离工作空间，没有创建平台作品。

TypeScript 检查、生产构建与 127 项测试通过。真实 Electron GUI 验证了单选默认 1、多选默认 2、文件夹默认 3，手动条数在选图与扫描后保留，取消选择保留原状态。明确选择的两个同内容文本分别生成两条图文，相同素材可保存两次；重启恢复指定文件，并在迁移后将文件列表映射到新目录。预览与任务详情截图已检查。

Windows v0.2.1 解包程序的 bundle 与最终构建逐字节一致，版本已核对；同一组 GUI 验收在打包程序再次通过。ZIP 文件包含 227 个配套文件，约 191.4 MiB。

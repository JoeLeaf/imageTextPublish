# v0.2.2 窗口与 Logo

移除 Windows 的“编辑 / 视图”菜单行，保留常用编辑快捷键；macOS 保留系统菜单栏的编辑角色。主窗口使用 44px 自定义标题栏，配置原生窗口按钮与拖动区域，macOS 使用原生交通灯按钮。侧栏与抽屉避让标题栏，启动加载界面也显示标题栏。

原创 logo 为蓝色图片卡片与浅青色发布箭头。SVG 源文件位于 assets/brand/logo.svg；PNG/ICO/ICNS 通过项目脚本生成，界面、运行时窗口与打包图标使用同一设计。

TypeScript 与生产构建通过。隔离 Electron 工作空间检查菜单为空、标题栏/侧栏位置、图标加载、拖动区域配置，以及原生窗口最大化/还原/最小化/关闭。窗口控制通过 BrowserWindow API 验证；浏览器自动化鼠标无法命中系统按钮，未把此项当作鼠标点击实测。Windows 显示截图已检查，完整素材与迁移 GUI 验收通过。macOS 未实机验证。

Windows v0.2.2 打包程序的主进程 bundle 与最终构建逐字节一致，打包后窗口检查再次通过。直接提取 EXE 图标并查看确认已替换默认 Electron 图标；应用未签名，保留图标与版本资源编辑。

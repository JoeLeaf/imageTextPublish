# v0.1 本机验收记录

日期：2026-10-12。环境：Windows x64、Node.js 22.16、Electron 44.7。使用临时数据目录与临时素材，未向平台提交作品。

## 已验证

- TypeScript 全量检查通过，生产构建通过。
- Vitest 6 个测试文件、52 项测试通过，包含真实 SQLite 持久化、替换事务回滚以及登录窗口生命周期。
- Windows 解包程序已生成，并对该可执行程序重复执行真实 Electron 窗口检查。
- Windows x64 ZIP 已生成，约 196 MiB；检查压缩包包含可执行程序和 `resources/app.asar`。
- GUI 添加账号；GUI 新建两条任务、每条两张图片、10 分钟间隔，扫描、整批预览与确认保存。
- 文本全文作为独立文案，图片以独立图集展示，不拆分首行为标题。
- SQLite 能在 Electron 环境读写；退出重开保留任务以及冻结图片选择。
- 未接通发布适配器时开始任务返回失败，数据库保持待确认，不生成平台成功记录。
- JSON 备份导出、空工作空间导入、目录重绑定及素材哈希核对。
- 导入后旧素材路径返回 403；重新绑定后恢复正常预览。
- 重复账号/任务导入：取消保留本机数据；确认替换前自动保存完整工作空间备份。

截图：`artifacts/batch-preview.png`、`artifacts/desktop-preview.png`。临时检查脚本 `artifacts/smoke-electron.cjs` 使用本机 Codex 内置 Playwright，属于本机验收工具，不是产品运行依赖。

## 登录修复验证（同日）

用户完成本机登录后，实际只读请求确认旧 `/web/api/user/info/` 返回业务失败，正确 `/web/api/media/user/info/` 返回 `status_code=0` 和顶层 `user.uid`。程序已改用该响应精确绑定用户 ID，诊断日志没有输出 UID、Cookie、手机号或其他个人字段的实际内容。

在用户现有持久登录环境下验证通过：自动检测变为 ready、关闭账号窗口后继续检查、应用退出再打开后后台检查，以及主窗口关闭时退出隐藏的账号窗口。没有上传素材或提交作品；发布签名桥接仍不可用。

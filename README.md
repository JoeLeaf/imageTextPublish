# 图文发布助手

<img src="assets/brand/logo.svg" alt="图文发布助手 Logo" width="88" />

面向个人使用的 Windows / macOS 本地桌面工具：选择文案与图片，为抖音多个账号生成图文批次，预览后按间隔或定时发布。使用表单配置，无需编写规则或代码；一次在一台电脑运行，可导出配置迁移到另一台。

[下载发行包](https://github.com/JoeLeaf/imageTextPublish/releases) · [使用说明](docs/usage.md) · [开发说明](docs/development.md) · [打包与发布](docs/releases.md)

## 当前能力

| 功能 | 说明 |
| --- | --- |
| 多账号 | 独立、持久的浏览器登录环境，任务选择对应账号 |
| 素材导入 | 文案与图片分别选择文件夹、单个文件或多个文件 |
| 自动组稿 | 每个文本文件对应一条文案；随机配图，默认每条 1 张，可按任务调整 |
| 批量与定时 | 默认条数等于有效文案文件数量；可调整条数、间隔及北京时间排期 |
| 发布控制 | 固定批次预览、开始、暂停、继续、取消，以及失败处理 |
| 迁移 | 配置导入导出、任务数据备份与本机素材路径重绑定 |

当前支持抖音图文；视频、其他平台、关键词配图、手机端及跨设备实时同步尚未实现。

发布通过创作者网页 SDK 签名与 HTTP / ImageX 上传链路完成，无需模拟点击发布按钮。Windows 的界面、素材、迁移流程和打包程序已验证，真实图片上传链路已验证；**最终创建作品的服务器成功回执、平台审核和 macOS 实机运行仍待验证**。平台网页接口变化时，发布适配器可能需要更新。

## 下载与运行

打开 [Releases](https://github.com/JoeLeaf/imageTextPublish/releases)，查看版本说明并下载对应系统与架构的文件。发行包无需安装 Node.js。

- Windows：下载 Windows x64 的 `.exe` 便携包并运行。如果使用解压版 ZIP，完整解压后运行其中的程序，保留同目录配套文件。
- macOS：Apple Silicon（M 系列）选择 `arm64`，Intel Mac 选择 `x64` 的 `.dmg`，打开后将应用复制到“应用程序”。当前没有签名和公证，首次运行可能被系统拦截，处理方法见 [打包与发布说明](docs/releases.md)。

仅下载实际已发布的附件；没有对应安装包时，可按 [开发说明](docs/development.md) 在本机从源码运行。

## 第一个任务

1. 在“账号管理”添加账号，打开独立账号窗口并完成登录，等待检测或点击“检查登录”。
2. 新建任务，分别选择文案和图片文件夹或文件。每个 TXT / MD / TEXT 文件的完整内容是一篇文案，图片独立组成图集。设置本批条数、每条图片数、间隔和开始时间。
3. 扫描素材、生成预览并逐条检查，然后确认保存。**保存不会自动发布，点击“开始”才执行发布。**
4. 首次使用建议只安排 1 条、1 张图片、仅自己可见，核对平台结果后再增加数量。

任务只在应用运行且电脑处于唤醒状态时执行。退出、关机或休眠后，需要检查任务并手动继续。结果不确定时会暂停该账号的后续提交，请在抖音核对作品再处理。

允许再次使用已发布的文案，不按发布历史查重。重试保留预览时选定的文案和图片。详见 [素材规则、异常处理与数据迁移](docs/usage.md)。

## 从源码运行

安装 Node.js 22（至少 22.12.0），在项目目录执行：

```bash
npm ci
npm run setup
npm run build
npm start
```

也可使用 `start-windows.cmd` 或 `start-mac.command` 启动。原生依赖安装、开发模式、测试后的运行时恢复与 Logo 定制见 [开发说明](docs/development.md)。自动构建与 GitHub Release 流程见 [打包与发布](docs/releases.md)。

## 技术栈

Electron、React、TypeScript、Node.js、Ant Design、SQLite（better-sqlite3）、Sharp。界面通过受控 IPC 调用主进程，本机文件、登录会话与任务执行由主进程管理。

文档导航与历史方案见 [docs/README.md](docs/README.md)。本项目参考了 [cv-cat/DouYin_Spider](https://github.com/cv-cat/DouYin_Spider) 的协议调研方向，发布适配器为本仓库独立实现。本项目与抖音及上述参考项目无官方关联。
